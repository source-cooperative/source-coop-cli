# Demos for PR #57 (`member`, `invitation`)

Recorded with [VHS](https://github.com/charmbracelet/vhs) against `stub_api.py`, a
stateful stand-in for source.coop's membership API (made-up accounts; signed in
as `dana`, an owner of `acme-lab`). `render.sh NAME...` re-records a tape against
a fresh stub. This branch only hosts the images for the PR description.

The `casts/` are the same sessions as asciicasts (uploaded to asciinema.org,
URLs in `casts/urls.txt`): `cast.sh NAME...` re-records them, with `drive.py`
replaying each tape's keystrokes into bash on its own pty.
